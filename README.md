# 🎮 Juego de Plataformas 2D - Godot

Un videojuego de plataformas en 2D desarrollado con **Godot Engine**, donde el jugador debe recorrer diferentes niveles, esquivar enemigos, recoger monedas y llegar al final del mapa para completar cada nivel.

## 📖 Descripción

El objetivo del juego es avanzar a través de los distintos escenarios superando obstáculos y evitando enemigos. Durante el recorrido, el jugador puede recolectar monedas para aumentar su puntuación mientras explora cada nivel.

## ✨ Características

- 🕹️ Movimiento fluido del personaje.
- ⬆️ Salto con físicas.
- 👾 Enemigos que deben esquivarse.
- 🪙 Sistema de recolección de monedas.
- 🗺️ Múltiples niveles con dificultad progresiva.
- 🏁 Meta al final de cada nivel.

## 🎮 Controles

|       Acción         |          Tecla           |
|----------------------|--------------------------|
| Mover a la izquierda |        ⬅️ o **A**       |
| Mover a la derecha   |         ➡️ o **D**      |
| Saltar               | ⬆️, **W** o **Espacio** |

## 🛠️ Tecnologías

- **Godot Engine**
- **GDScript**

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio:
   ```bash
   git clone https://github.com/tu-usuario/tu-repositorio.git
   ```
